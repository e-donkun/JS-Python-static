# JS-Python Editor（静的版）

高校「情報Ⅰ」向けの、ブラウザだけで動く Python 学習用エディタです。

- サーバやログインは不要です。Python は [Pyodide](https://pyodide.org/)（WebAssembly）でブラウザの中で実行されます。
- コードの保存先は、お使いのブラウザ内（localStorage）だけです。ほかへは送信されません。
- ダウンロードボタンで、書いたコードをファイルとしてパソコンに保存できます。パソコンのファイルを読み込むこともできます。

このリポジトリは、自動で生成・反映される公開用の成果物です。直接編集しないでください（編集しても次の更新で上書きされます）。
